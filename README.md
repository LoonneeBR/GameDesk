# 🎮 GameDesk

O **GameDesk** é uma plataforma web desenvolvida para incentivar e recompensar colaboradores que se destacam e atingem suas metas. O projeto utiliza elementos de gamificação para transformar o ambiente de trabalho em uma experiência mais engajadora.

## 🚀 Sobre o Projeto
Este repositório foi criado para praticar e consolidar conceitos fundamentais de desenvolvimento web front-end. 

<img width="1365" height="638" alt="image" src="https://github.com/user-attachments/assets/07a120ab-060f-4a57-875e-c94b233662d4" />


O sistema permite:
* Visualizar regras de pontuação.
* Consultar recompensas disponíveis.
* Acompanhar metas de desempenho.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação do conteúdo das páginas.
* **CSS3**: Estilização, layout responsivo e design visual.
* **JavaScript**: Lógica de interação e dinamismo do site.

## 📂 Estrutura de Arquivos
* `index.html`: Página principal (Dashboard).
* `rules.html`: Regulamento do programa de pontos.
* `rewards.html`: Catálogo de prêmios e incentivos.
* `imagens/`: Repositório de assets e ícones do projeto.
